# RE Docs

**Professional Real Estate Document Platform**

Fill out, print, and send professional real estate contracts in minutes.

## Features
- 10 auto-filling contracts (Buyer Rep, Listing, Lease, PSA, Commission, Referral, LOI, Disclosure, Move-In/Out, Renewal)
- 6 role-specific dashboards (Buyer's Agent, Listing Agent, Property Manager, Broker, Investor, Dual Agent)
- Commission calculator with live math
- Contract deadline calendar with Google Calendar integration
- Email contracts to counterparty
- Thank-you email to clients
- Blog + About/Reviews pages

## Pricing
- $19.99/month or $29.99/year

## Tech
Single-file HTML app with localStorage auth and subscription gate.
